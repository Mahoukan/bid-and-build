## Changes resulting from the audit

- Closed the shutdown gap for async administrator password/image work after its HTTP client disconnects; stop new HTTP/socket admission and drain room/admin tasks before SQLite closes. Duplicate signals are harmless; the 25-second emergency deadline fits a documented 30-second container stop period.
- Added explicit trusted-proxy IP/CIDR configuration, defaulting to no trust, so deployed IP rate limits can distinguish clients without accepting arbitrary forwarded addresses. The operator must configure the actual proxy network and block direct backend exposure.
- Added validated backup/restore commands and exercised them against independent storage. Content images are database BLOBs, so the old generic guide's separate-upload assumptions were corrected.
- Finished Docker packaging and Linux CI; added identical real-server persistence scenarios for local compiled output and a disposable Docker volume. Added full sample UI flows to close the final acceptance coverage gap.
